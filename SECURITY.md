# Security

This repository contains a public profile README, SVG assets and their GitHub Actions generators. It does not host the applications linked from the profile.

For an exposed credential or a vulnerability in this repository's automation, email **rajveer.r.vadnal@gmail.com** privately. Include the affected file or workflow, impact and reproduction steps; do not include live credentials in public issues.

For a linked project, use that project's own security policy. Ordinary profile corrections can be reported in a public issue.
