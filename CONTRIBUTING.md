# Contributing

This repository powers Rajveer Vadnal's GitHub profile. The layout follows [Avi Vashishta's profile](https://github.com/AVIVASHISHTA29/AVIVASHISHTA29): contribution graph, ASCII portrait beside statistics, then link badges. Rendering code is independently implemented; portrait art uses Rajveer's own supplied photograph, not the reference author's photo or assets.

## Editing

- Preserve the three-section layout in `README.md`. Keep the portrait and statistics at the same `840 × 880` viewBox, displayed side by side at `420px` each. Keep real links and meaningful image alt text.
- `scripts/gen_profile.py` owns the ASCII portrait, reference-style graph and six-tile/monthly statistics card. `data/portrait.json` contains only derived ASCII rows, not the original photograph or metadata. Regenerate `assets/rajveer-ascii.svg` and its static equivalent from those rows; do not edit it by hand.
- The original photograph, segmentation model, and prepared image remain local. To replace the portrait, prepare a tightly cropped square with a clean white or transparent background, then use the optional `--input` conversion below. Pillow is needed only for that one-time local conversion, not CI.
- `scripts/gen_stats.py` fetches GitHub data and generates `assets/contrib-heatmap.svg`, `assets/stats.svg`, and `docs/activity.md` from one snapshot. Every graph cell, card metric, and monthly total has a text equivalent. API or rendering failures leave the previous dated output intact.
- The portrait reveals once in 5.8 seconds and remains visible. The graph, counters, and bars also animate once. Explicit `<picture>` sources select truly static equivalents under reduced motion, exposing final values/portrait immediately. The graph also has explicit light-theme variants so its total remains readable. No JavaScript runs in the README.
- The links section uses four equal `132 × 44` locally hosted terminal buttons, generated by `scripts/gen_profile.py`. Portfolio is the primary action; company, LinkedIn, and email are secondary. Keep this row compact and leave navigation in native Markdown anchors. No remote badge service is required.
- Keep portfolio/resume links on `https://rajveer.codes`, and the neuratile homepage on `https://neuratile.rajveer.codes`. GitHub repository links remain source links.
- Project details, attribution, counting rules, and evaluation limitations remain in `docs/profile-evidence.md`. The earlier design templates/assets and interactive atlas are retained as an archive, not the active profile layout.
- `scripts/gen_projects.py` generates the public repository index. Keep public-only filtering, organization namespaces, and fork labels.

## Checks

```bash
python -m py_compile scripts/*.py
python -m unittest discover -s scripts -v
python scripts/gen_profile.py --check
python scripts/gen_terminal.py --check
python scripts/gen_atlas.py --check
git diff --check
```

Preview GitHub-rendered Markdown at desktop/mobile sizes. Check the actual photo likeness, row-by-row reveal, final animation hold, reduced motion, image loading, and all badge destinations.

Regenerate the committed portrait without the original JPG or Pillow:

```bash
python scripts/gen_profile.py
```

Optional one-time portrait replacement (Pillow must be installed locally):

```bash
python scripts/gen_profile.py --input /path/to/prepared-square-portrait.png
```

Refresh daily data using existing `gh` authentication or `GITHUB_TOKEN`:

```bash
python scripts/gen_stats.py
python scripts/gen_projects.py
```

The workflow validates pull requests and `main`, then refreshes data on `main` and the daily schedule. Only publishing receives write permission. Generated-only commits do not recursively trigger another refresh.
