# Contributing

This repository powers Rajveer Vadnal's GitHub profile. Corrections to links, wording, data, and presentation are welcome.

## Editing

- Keep `README.md` terminal-first: restrained monospace artwork, native Markdown project listings, and ordinary clickable links. No fake logs, invented metrics, badge walls, or remote image-service dependencies.
- `scripts/gen_terminal.py` owns the terminal identity, shared SVG primitives, themes, and calendar/activity layouts. Run it to regenerate the four identity variants. Do not hand-edit generated assets.
- `scripts/gen_stats.py` fetches one contribution calendar and paginated owned public non-fork repository totals from GitHub GraphQL. It generates all eight calendar/activity variants and `docs/activity.md` (summary metrics and every daily count) from the same snapshot. API failures leave the last dated images intact and fail the workflow rather than inventing new data.
- Detailed descriptions, contribution attribution, and evaluation limitations belong in `docs/profile-evidence.md`. Keep image alt text meaningful. SVG-internal links are not navigation when embedded in GitHub; use native Markdown links.
- The older panels remain generated by `scripts/gen_atlas.py`. They and `docs/execution-atlas.html` preserve the previous design and evidence. Atlas paths describe project roles, not implemented integrations.
- `assets/project-index.svg` and `docs/public-repositories.md` are generated by `scripts/gen_projects.py`. Include public repositories only, mark forks, and preserve organization namespaces. Inclusion does not imply sole authorship.
- Keep the portfolio and resume links on `https://rajveer.codes`.

## Preview and checks

Check desktop and narrow widths in light/dark themes and reduced motion. Validate links, alternative text, and SVG readability. No runtime JavaScript is needed for the README.

```bash
python -m py_compile scripts/*.py
python -m unittest discover -s scripts -v
python scripts/gen_terminal.py --check
python scripts/gen_atlas.py --check
git diff --check
```

Regenerate the identity assets:

```bash
python scripts/gen_terminal.py
```

Refresh activity and the public catalog using existing `gh` authentication or `GITHUB_TOKEN`:

```bash
python scripts/gen_stats.py
python scripts/gen_projects.py
```

The `Refresh profile assets` workflow validates pull requests and `main`. On `main` and the daily schedule it also refreshes the GitHub API assets. Only the publishing job receives write permission. Its generated-only commits do not recursively trigger refreshes.

Open a focused pull request describing the correction and how you checked it.
